快速部署

选择证书、填写服务域名和反向代理端口，生成命令后复制到目标 Linux 服务器执行。

1. 快速部署证书

在目标 Linux 服务器以实际部署用户执行，证书保存到该用户的 ~/ssl/证书域名/。需要 Bash、wget、OpenSSL、crontab 和 flock，并能访问证书下载地址。自动保留已有 cron，每天 03:00（目标服务器时区）更新证书；重复执行不会重复添加该证书的任务。

后续更新需要 nginx 位于 /usr/sbin/nginx；普通用户需要配置无需密码的 nginx 检查和重载权限，cron 无法交互输入 sudo 密码。

2. 快速配置 nginx
请先安装并启动 nginx，请使用与上方证书部署相同的用户执行。家目录由命令自动读取。需要 sudo 权限；主配置需在 http 块内加载 /etc/nginx/conf.d/*.conf。写入前备份现有配置，检查通过后重载，失败时恢复原配置。请确保 nginx 主进程能够访问用户家目录中的证书。
